# Интерактивная лекция для Moodle

В папке находится одностраничный сайт лекции «Молодёжный сленг XXI века: от новых слов к современному словарю».

- `index.html` — оформление, навигация, анимации и интерактивные элементы.
- `source.txt` — текст лекции, вынесенный отдельно, чтобы его можно было править без изменения дизайна.

## Что есть на странице

- адаптивный дизайн для телефона и компьютера;
- навигация по разделам;
- индикатор прогресса чтения;
- мягкие анимации появления текста;
- режим чтения и печать/сохранение в PDF;
- учёт настройки «уменьшить движение» в системе.

## Публикация

После слияния ветки в `main`, если GitHub Pages включён для репозитория и публикует корень ветки `main`, страница будет доступна по адресу:

`https://vichka89.github.io/github-slideshow/moodle-lecture/`

Если GitHub Pages в репозитории не включён, его нужно включить в Settings → Pages. Для Moodle можно добавить опубликованный адрес как URL-ресурс. Правила безопасности Moodle могут ограничивать запуск HTML/JavaScript, вставленного напрямую в редактор, поэтому внешний URL обычно надёжнее.

**Важно:** исходный текст вынесен отдельно в `source.txt`. Если нужно менять содержание лекции, редактируйте только этот файл.
